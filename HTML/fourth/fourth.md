## Block
-> A block-level element starts on a new line and generally takes up the full available width of its parent.

<div>
<p>
<h1>
<section>
<header>
<footer>

## Inline 
An inline element does not normally start on a new line and takes up only as much width as its content requires.
<span>
<a>
<strong>
<em>

## div
<div> is a generic block-level container used to group and organize other HTML elements.

<div>
  <h1>Student</h1>
  <p>Gourav is a developer.</p>
</div>

<div>      → Generic container
<section>  → Meaningful section
<nav>      → Navigation
<footer>   → Footer content

> <div> is a generic, non-semantic container used to group elements, while elements like <nav>, <section>, <header>, and <footer> are semantic containers that describe the meaning/purpose of their content and help structure the web page.


## HTML button
-> <button> is used to create an interactive button on a web page.
    - Submit form
    - Open menu
    - Delete item
    - Call JavaScript function

## HTML Iframe
-> <iframe> is used to embed another HTML document or external content inside the current web page.

<iframe
  src="https://example.com"
  width="600"
  height="400">
</iframe>
