## HTML Layout
HTML layout refers to the structure/arrangement of different sections of a web page.
<header>
<nav>
<main>
<section>
<article>
<aside>
<footer>

## Benifits of Layout
Gives the page a clear structure
Improves accessibility
Helps search engines understand the page structure
Can help with SEO



## Semantic elemetns 
-> Semantic elements clearly describe the meaning and purpose of their content.

## non semantic 
-> Non-semantic elements do not describe the meaning or purpose of their content. They are mainly used for generic grouping or styling.
<div>
<span>

## HTML entites
-> HTML entities are used to represent special characters or characters that have a special meaning in HTML.

&lt;   → <
&gt;   → >
&amp;  → &
&quot; → "
&nbsp; → non-breaking space

## HTML Symbols
-> You can display many Unicode characters directly
<p>© 2026</p>
<p>₹ 500</p>
<p>✓ Done</p>

## HTML encoding-
 means converting text into a proper format of bytes so that computers and browsers can understand and display it correctly.

## UTF-8 
helps the browser correctly interpret and display characters in the HTML document.

## HTML vs XTHML
HTML is a forgiving markup language used to structure web pages, while XHTML is a stricter version of HTML that follows XML syntax rules.
