CSS Overflow Examples

1. Overflow: Visible

This is a very long text. The extra content will be visible outside the box because overflow is set to visible.

2. Overflow: Hidden

This is a very long text. The extra content will be hidden because overflow is set to hidden.

3. Overflow: Scroll

This is a very long text. Scrollbars will always be available because overflow is set to scroll.

4. Overflow: Auto

This is a very long text. Scrollbars will appear only when the content is larger than the container.

5. Text Ellipsis

This is a very long text and we want to show three dots when the text does not fit inside the container.

6. Show Whole Text

This is a very long text. Instead of hiding the text or showing ellipsis, the text will move to multiple lines so that the complete text can be displayed.

7. Horizontal Overflow

This is a very long single line of text that will create a horizontal scrollbar because the content is wider than the container.
