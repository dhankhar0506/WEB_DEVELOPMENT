## CSS Flexbox
Flexbox is a layout model for arranging items (horizontally or vertically) within a container

## With Flexbox:
    Easy horizontal alignment
    Easy vertical alignment
    Equal spacing
    Responsive layouts

## Flex Container Properties =>  The parent (container) element, where the display property is set to flex or inline-flex
    display
    flex-direction
    justify-content
    align-items
    flex-wrap
    align-content
    gap
    flex-flow
