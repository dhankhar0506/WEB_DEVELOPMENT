1. Position: Static

Static Box

Default position. Element stays in the normal document flow.

2. Position: Relative

Relative means the element can move from its original position in different directions.

Relative Box :move from your original position

The box is moved from its original position, but its original space is still preserved.

3. Position: Absolute

Absolute

This is the parent container.

Element is positioned relative to its nearest positioned parent/ancestor and removed from normal flow.

4. Position: Fixed

Look at the bottom-right corner. The "Fixed" button stays there even when you scroll.

→ Element is fixed to the browser screen and stays there while scrolling.

Offsets are the properties used to control the position of an element:

  • top
  • bottom
  • left
  • right

z-index controls which element appears in front of or behind another element.

.box1 { position: relative; z-index: 1; }
.box2 { position: relative; z-index: 2; }
