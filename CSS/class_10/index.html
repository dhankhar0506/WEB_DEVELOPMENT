CSS Units Examples

1. px - Pixels

A fixed-size unit.

The declared value remains 100px even if the screen size changes.

200px × 100px

2. % - Percentage

Relative to the size of the parent/container in many properties.

Width = 50% of parent

3. em

Relative to the font size of the element's context.

This text uses em.

4. rem

Relative to the root (html) font size.

This text uses rem.

5. vw - Viewport Width

Relative to broswer width

Width = 50vw

6. vh - Viewport Height

relative to broswer height

Height = 30vh

7. vmin

20vmin

8. vmax

20vmax

9. ch

This paragraph has a width based on the number of characters.
