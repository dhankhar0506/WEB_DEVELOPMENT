## MATH 
-> Math is a built-in JavaScript utility object that provides mathematical constants and methods.

1. Math.round() => Rounds to the nearest integer.
    ->Math.round(4.4); // 4
    Math.round(4.6); // 5
    Math.round(4.5); // 5

2. Math.floor() => Rounds down toward
    Math.floor(4.9);  // 4
    Math.floor(4.1);  // 4
    Math.floor(-4.2); // -5

3. Math.ceil() => Rounds up toward +Infinity.
    Math.ceil(4.1); // 5
    Math.ceil(4.9); // 5

4. Math.trunc() => Simply removes the decimal part.
    Math.trunc(4.9);  // 4
    Math.trunc(-4.9); // -4

5. Math.max(a,b,c)
6. Math.min(a,b,c)

7. Math.abs(-10) // 10
    -Returns the absolute/non-negative value.

8. Math.random() (0-1)
    -> example .72845
    -> Math.floor(Math.random() * 10)    // (0-9)
    -> Math.floor(Math.random() * 10) + 1   // (1-10)
9. Math.sqrt()
    ->Math.sqrt(25); // 5
    -> Math.sqrt(100); // 10

10. Math.pow()
    -> Power of a number.
    -> Math.pow(2, 3);// 8
